# The RUNTIME install for the service image. `build/Dockerfile` installs this file and nothing
# else, so every line here lands in the production image.
#
# ⭐ THIS FILE IS THE RESOLVED CLOSURE OF `pyproject.toml`'s `[service]` EXTRA, pinned.
# `[service]` states the contract in ranges; this states one reproducible resolution of it, because
# an image is a specific set of bytes and a range is not. Two lists that name different packages
# would make "what the service needs" a question with two answers, and the image would be the one
# nobody reads. Keep them in step: a package added to `[service]` is added here, and nothing is
# added here that `[service]` does not name.
#
# TEST TOOLING DOES NOT BELONG IN A RUNTIME IMAGE and is declared in `[dev]` instead. CI installs
# `-e '.[dev]'` alongside this file; the image installs this file alone.
#
# `agience-prism-py` is the one `[service]` requirement absent here on purpose: it is not on PyPI,
# and the Dockerfile installs it from the `prism` build context in the same builder stage.
